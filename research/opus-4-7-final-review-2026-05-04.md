### II.1. 🔴 БЛОКЕР: Intro-popup focus trap сломан

`assets/js/lib/intro.js:107-114`

```js
function onKey(e) {
  if (e.key === 'Escape') { e.preventDefault(); dismiss(); }
  if (e.key === 'Tab') {
    e.preventDefault();
    overlay.querySelector('.intro-btn')?.focus();
  }
}
```

**Что происходит:** при любом нажатии Tab (с Shift или без) фокус **всегда** возвращается на кнопку «Понятно». Внутри попапа есть **четыре** фокусируемых элемента:
- 2 таба (`.intro-tab` reader / streamer)
- кнопка копирования эфирного текста (`[data-copy]`, видна только в streamer-режиме)
- ссылка на репозиторий (`.intro-repo`)
- кнопка «Понятно» (`.intro-btn`)

**Воспроизведение:**
1. Откройте сайт с клавиатуры (Tab / Shift-Tab).
2. Попап ловит фокус на «Понятно».
3. Tab → снова «Понятно». Никогда не дойти ни до табов, ни до кнопки «копировать», ни до GitHub-ссылки.

**Эффект:**
- Стримеру с клавиатурой **невозможно** переключиться в режим «Для эфира» без мыши.
- Невозможно нажать «копировать текст для эфира» с клавиатуры.
- Невозможно дойти до GitHub-ссылки (хотя она единственный способ заявить о репозитории сразу).

**Фикс** — заменить тривиальный тrap на цикл, как в `assets/js/lib/modal.js:13-25`:

```js
function focusableIn(el) {
  return Array.from(el.querySelectorAll(
    'a[href], button:not([disabled]), [tabindex]:not([tabindex="-1"])'
  )).filter(n => n.offsetParent !== null && !n.hasAttribute('hidden'));
}

function onKey(e) {
  if (e.key === 'Escape') { e.preventDefault(); dismiss(); }
  if (e.key !== 'Tab') return;
  const f = focusableIn(overlay);
  if (!f.length) return;
  const first = f[0], last = f[f.length - 1];
  if (e.shiftKey && document.activeElement === first) {
    last.focus(); e.preventDefault();
  } else if (!e.shiftKey && document.activeElement === last) {
    first.focus(); e.preventDefault();
  }
}
```

Дополнительно: `focusableIn` должен пересчитываться **при переключении табов**, чтобы скрытая `[data-copy]` правильно выпадала из списка в reader-режиме.

**Уровень:** 🔴 must-fix (блокирует доступность за 2 строки до релиза).

**Лайфхак:** если опасаетесь — откройте `assets/og/home.png` в просмотрщике и сличите с `home.svg` визуально. SVG-исходники сами по себе при наличии шрифтов в браузере выглядят правильно (только что проверил).

### III.2. Эфирный текст — 🟡 should-fix

См. I.6. Резюме:

- **Длительность:** ~43–51 сек, не «~30 сек» как заявлено.
- **Стилистически** звучит технически и казённо при чтении вслух (особенно перечисление «государственные публикации Государственной Думы и ЦИК России, тексты федеральных законов, материалы федеральных СМИ» — сложно произнести без запинки).
- **Предлагаю две версии** в UI: «короткая» (15 сек, ~30 слов) и «полная» (30 сек, ~60 слов). Toggle между ними в той же серифной карточке. Короткая версия — для «дисклеймера в шапке стрима»; полная — для интро-эфира. Стримеры выбирают по контексту.

Образец короткой:

```
Это сайт-эксперимент по открытым данным. Автор — технический специалист,
не политолог. Сайт никого не призывает к действиям; каждое утверждение —
со ссылкой на первоисточник. Смотрите цифры, делайте выводы.
```

≈ 25 слов / 12-15 секунд.

### III.5. Adversarial UX — что атакуют

#### Скептик-провластник
**Вероятные атаки:**
1. «Источники иноагенты — Meduza, iStories, Голос». **Защита уже встроена**: первичные ссылки идут на ЦИК, kremlin.ru, ТАСС, РГ. В каждом разделе method-note начинается с **государственных** источников.
2. «72% — это с учётом одномандатных округов, а не процент за партию». **Защита уже встроена**: hero-deck явно говорит «49,82% голосов → 72% мест» и весь сайт об этом разрыве.
3. «Это всё работает в США/Британии/Германии — нормальная мажоритарная система». **Защита**: counterfactuals и история 2005–2024 показывают, что система **выбрана** и **изменена** именно в направлении максимизации мандатов одной партии. Полезно (но необязательно) добавить одну строку: «Аналогичные смешанные системы есть в Германии, Италии, Японии — но без 5-кратной диспропорции».

#### Фактчекер
**Слабые места:**
- Цифра «+11 / 115 / 20» — действительно зависит от модели (см. I.5). **Митигирующая сноска снимет вопрос.**
- Tushinsky finalPct (см. I.1) — номер строки нужно либо привести к % от всех бюллетеней, либо явно подписать.
- Heatmap использует `pVals = [60, 50, 40, 30, 25, 20]` — округлённые значения. Если кто-то будет искать «50%» как «факт 2021», увидит звёздочку — ему станет ясно, что 50 ≈ 49,82. Норм.

#### Журналист
**Топ-5 самых tweetable цитат:**
1. **«49,82% голосов превращаются в 72% мест в Думе»** — без контекста корректно, легко чекается. ✓
2. **«В 8 из 15 московских округов кандидаты, лидировавшие по бумаге, проиграли после публикации ДЭГ»** — без контекста корректно. ✓
3. **«ЕР получает из бюджета больше, чем все четыре оппозиционные партии вместе»** — без контекста корректно. ✓
4. **«Из 18 ограничительных законов 2019–2025 только 2 вызвали реальное "против" от оппозиции»** — без контекста корректно. ✓
5. **«~14 млн нарисованных голосов 2021 (Шпилькин)»** — корректно, но при цитировании надо обязательно сохранить «по оценке независимых аналитиков», иначе становится категоричным утверждением. **Защита**: на сайте оно везде помечено как оценка.

🟢 **Все 5 цитат выдерживают вырезание из контекста.**

## Итог

Сайт **готов к публикации** при условии исправления одного 🔴-блокера (focus trap в попапе — 5 минут работы). Остальные четыре правки — улучшение качества, не блокеры; их можно подвести в патч после первого прогона по медиа.
