# Заметки по доступу к источникам

Эта заметка фиксирует, какие из приоритетных источников были фактически доступны при подготовке исследования и какие пришлось обходить через зеркала.

## Поведение RU-источников по типу клиентского IP (на 2026-05-05)

С RU-IP домашнего провайдера напрямую доступны:
- ✅ `zakupki.gov.ru` (HTTP 200, 2.4 МБ) — единая база госконтрактов
- ✅ `minjust.gov.ru` (HTTP 200, 55 КБ) — реестр иноагентов и партий
- ✅ `sozd.duma.gov.ru` (HTTP 200) — карточки законопроектов
- ✅ `gosuslugi.ru` (HTTP 200)

С зарубежного хостингового AS блокированы (DDoS-защита от хостинговых AS, блок жёсткий — TCP RST или таймаут):
- ❌ `cikrf.ru` (мгновенный connection refused)
- ❌ `vote.duma.gov.ru`, `api.duma.gov.ru`, `duma.gov.ru` (timeout)
- ❌ `kremlin.ru`, `publication.pravo.gov.ru` (timeout)
- ❌ `declarator.org` (timeout с хостинга; работает с RU VPS)
- ⚠️ `egrul.nalog.ru` (307 без content)

Эти сайты пускают только **конечные клиентские** IP домашних провайдеров; запросы из зарубежных хостинговых AS блокируются на L4.

## Стратегия обхода

1. **Прямой первоисточник, где возможно.** Все ссылки на ФЗ и поимённые голосования — на `sozd.duma.gov.ru` (стабильно отвечает).
2. **Деловая пресса как мост к первоисточнику.** Когда Forbes / РБК / Ведомости / Коммерсант цитируют контракт zakupki.gov.ru № X на сумму Y, в досье даётся ссылка на статью, а в скобках — ссылка на сам контракт; оба источника читатель может проверить независимо.
3. **iStories и «Проект» — проверенные расследовательские монографии.** Используются как 🟠-источник, но при наличии второго подтверждения статья поднимается до 🟡.
4. **СПАРК-Интерфакс / Контур.Фокус** — закрытые базы. Используются только цитированием СМИ, которые имеют подписку. В досье помечается «по данным СПАРК, цитируемым в [издание]».
5. **Pandora Papers / OCCRP** — для зарубежной собственности. Прямой доступ к индексам утечек работает (offshoreleaks.icij.org); конкретные ИНН и фамилии проверяются.

## Что **в принципе нельзя** сделать в этом исследовании из-за ограничений доступа

- Полностью отскрейпить голосования по ИНН по всей VIII Думе с разбивкой по фракциям и поимённо. Это требует прямого доступа к `vote.duma.gov.ru` или подписки на Sozd-агрегаторы.
- Полностью пробить госзакупки по ИНН лидеров партий. Требуется доступ к `zakupki.gov.ru` или СПАРК.
- Полностью верифицировать финансовые отчёты партий по годам. Требуется `cikrf.ru/analog/finansy/`.

Все эти места явно перечислены в `99-open-questions/verification-checklist.md` с конкретным указанием, какой запрос куда нужно сделать.
