# Приоритеты источников

В соответствии с ТЗ `research/compromat.md`, иерархия (от высшей к низшей):

## 1. Государственные реестры и базы данных

- **zakupki.gov.ru** — Единая информационная система в сфере закупок. Госконтракты, заказчики, поставщики, суммы. Сложно искать по ИНН без доступа из РФ.
- **egrul.nalog.ru** — Единый государственный реестр юридических лиц. Учредители, директора, виды деятельности. Капча, но API работает.
- **rkn.gov.ru** — реестры Роскомнадзора. Для нашего сюжета малоинтересен (мы анализируем партии, а не СМИ); используется в секции про иноагентов.
- **publication.pravo.gov.ru** — официальное опубликование актов. Незаменимо для ФЗ, постановлений правительства, указов президента. Дублёры — `consultant.ru`, `garant.ru`.
- **kremlin.ru** — указы президента, протоколы заседаний с участием Путина, поручения.
- **declarator.org** — общественный реестр деклараций. Государство свернуло публикацию деклараций депутатов в 2022, но архив 2010–2022 остаётся.
- **Минюст РФ (minjust.gov.ru)** — реестр партий, реестр НКО, реестр иноагентов. Часть данных доступна через минюстовский раздел, часть — только через запрос.
- **СПАРК-Интерфакс / Контур.Фокус** — закрытые базы, цитируются через СМИ.
- **vote.duma.gov.ru / api.duma.gov.ru** — поимённые голосования, стенограммы.

## 2. Документы партий

- Уставы (на сайтах партий или в реестре Минюста).
- **Финансовые отчёты партий в ЦИК** (`cikrf.ru/analog/finansy/`) — годовые и квартальные. Ключ к секции B каждого досье.
- **Декларации кандидатов** — в карточках кандидатов на сайте ЦИК.

## 3. Деловая пресса с задокументированными расследованиями

В этом исследовании первый круг доверия:

- **Forbes Russia** (до закрытия — forbes.ru, после — англоязычная редакция).
- **РБК** (rbc.ru) — особенно расследовательский отдел.
- **Ведомости** (vedomosti.ru) — после «реструктуризации» 2020 г. качество расследований снизилось, но архив до 2020 авторитетен.
- **Коммерсантъ** (kommersant.ru) — деловая пресса с глубоким архивом.
- **The Bell** (thebell.io) — англоязычное продолжение редакции «Ведомостей»/Forbes; после признания иноагентом — европейское издание.

## 4. Независимые расследовательские издания

- **iStories** (istories.media) — расследовательская журналистика; основные сюжеты по российской элите 2020–2025. Статус: иноагент.
- **«Проект»** (proekt.media) — расследования; статус: «нежелательная организация» с 2021. Использование первоисточника осторожное, но сами публикации авторитетны.
- **«Новая газета»** (novayagazeta.ru) — приостановлена с марта 2022; преемник «Новая газета. Европа» (novayagazeta.eu).
- **«Агентство»** (agents.media) — расследования с 2021; статус иноагента.
- **«Медуза»** (meduza.io) — статус иноагента + «нежелательная организация».
- **BBC Russian** (bbc.com/russian) — расследовательский отдел Олега Болдырева и Ильи Барабанова.
- **Радио Свобода** / **«Сибирь.Реалии»** / **«Север.Реалии»** — статус иноагента; региональные расследования.
- **The Insider** (theins.ru) — расследования по биографиям, недвижимости.
- **Bellingcat** — для зарубежных следов и OSINT.

## 5. Академические работы и книги

- **Григорий Голосов** (Европейский университет в СПб) — выборные системы, спойлеры, «Сравнительная политология» и многочисленные статьи.
- **Александр Кынев** — региональная политика, парламентские выборы.
- **Владимир Гельман** (Helsinki) — авторитарная политика, режимный анализ.
- **Татьяна Становая** (R.Politik) — кремлёвские группы влияния.
- **Андрей Перцев** («Медуза», ранее «Коммерсантъ») — внутриполитическая аналитика.

## Ограничения по «экстремистским» организациям

Согласно ТЗ, материалы признанных в РФ «экстремистскими» организаций (ФБК А. Навального, «Антикоррупционный фонд», «Штабы Навального») **не используются как первоисточники**. Если факт известен только по их публикациям — он либо не используется, либо помечается 🟠 с пометкой «известно только из источника-экстремистской организации».

## Список «нельзя цитировать как первоисточник» в РФ

| Организация | Статус | Использование в досье |
|---|---|---|
| ФБК | экстремистская | факт из ФБК → ищется второе независимое подтверждение, иначе не используется |
| «Открытая Россия» | нежелательная | как ФБК |
| «Мемориал» (закрыт) | ликвидирован | архив исторический, разрешён к цитированию как академический источник |
| «Медуза», iStories, «Новая газета. Европа», «Дождь», «Радио Свобода», The Insider, BBC Russian | иноагент / нежелательная | разрешено как 🟠 |

Это **исключительно** регуляторное соображение: материал, который можно показать в РФ без юридического риска для читателя, должен опираться на источники, не находящиеся в зоне «экстремизма». Это никак не влияет на качество фактов «Медузы» или iStories — но влияет на то, что можно процитировать в инфраструктуре сайта `im-not-a-human.github.io`.
