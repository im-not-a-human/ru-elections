# Сводный анализ поимённых голосований 2019–2025

> Анализ голосования всех пяти фракций по ключевым ограничительным законам 2019–2025 гг. **Источник первичных данных** — `api.duma.gov.ru` (см. raw XML/JSON в [`05-evidence/duma-api/votes/`](../05-evidence/duma-api/votes/) и индекс [`05-evidence/duma-api/INDEX.md`](../05-evidence/duma-api/INDEX.md), машинно-читаемая сводка [`05-evidence/duma-api/votes-summary.csv`](../05-evidence/duma-api/votes-summary.csv)). Все числа в таблицах ниже — из `<resultsByDeputy>` API на 2025-2026, а не из пересказов СМИ.

## Метод

- За единицу анализа берётся **III чтение** ключевого закона (если оно состоялось; иначе — финальное голосование).
- Для каждого закона фиксируется: дата, № карточки, общий результат, фракционная разбивка (за/против/возд./отс.).
- Доля поддержки = процент голосований «за» от общего числа в выборке.
- **Поимённые данные**: все 28 голосований скачаны через `api.duma.gov.ru` (см. `05-evidence/duma-api/votes/<short-name>.xml`); в каждом файле `<resultsByDeputy>` фиксирует позицию каждого депутата.
- **Индивидуальные диссиденты** автоматически выделены парсером `parse_votes.py` и сведены в [`05-evidence/duma-api/dissidents.md`](../05-evidence/duma-api/dissidents.md): два типа — «активный диссент» (голосовал против фракционной линии) и «тактическое отсутствие» (отсутствовал, когда фракция голосовала «за»).
