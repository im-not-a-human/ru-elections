## Открытые точки верификации

См. `99-open-questions/verification-checklist.md`. Применительно к СРЗП ключевые открытые точки:

1. **Построчные отчёты ЦИК 2018–2025 гг.** — выгрузка по строкам «бюджет / физлица / юрлица / взносы / займы».
2. **Идентификация крупнейших юрлиц-жертвователей** через ЕГРЮЛ + zakupki.gov.ru: ООО «Инвестстрой-Н», ИК «РУСС-ИНВЕСТ», ООО, связанные с ЧКПЗ Гартунга.
3. **Госконтракты ПАО «ЧКПЗ» 2018–2025 гг.** — выгрузка по ИНН 7449006184 через zakupki.gov.ru.
4. **Связи А. Бабакова с энергетическим сектором Украины** — расследования iStories требуют отдельной верификации.
5. **Финансовые потоки полка «Оплот»** Росгвардии — открытая точка из [независимого исследования 1, разд. 10](../../../independed_research_result_1.md).
6. **Журналистская гипотеза** о пожертвованиях структур, связанных с Ковальчуками, в кампанию «За правду» 2020 г. — открытая точка.
7. **Полные суммы избирательных фондов 2018, 2021** с разбивкой по источникам.
8. **Декларации депутатов фракции 2018–2024 гг.** через declarator.org.
9. **Полный поимённый список соавторов ФЗ-340** (цифровой рубль) — открытая точка.
10. **Стенограмма заседаний этической комиссии Думы по электронным повесткам** (если такие были) — публичная стенограмма не опубликована.
11. **Публикация материалов съезда 25.10.2025** — открытая точка для верификации содержания выступления Кириенко.
12. **Дальнейшая военная активность Прилепина 2025–2026 гг.** — открытая точка (по публикациям Коммерсанта 2025 г. — он планировал подписать новый военный контракт).
