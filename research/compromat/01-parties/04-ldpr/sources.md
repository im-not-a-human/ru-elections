## Открытые точки верификации

См. `99-open-questions/verification-checklist.md`. Применительно к ЛДПР ключевые открытые точки:

1. **Построчные отчёты ЦИК 2017–2025 гг.** — выгрузка по строкам «бюджет / физлица / юрлица / взносы / займы».
2. **Сверка ИНН депутатов фракции через ЕГРЮЛ + zakupki.gov.ru** — на наличие/отсутствие коммерческих структур с госзаказами.
3. **Полные суммы избирательных фондов 2018, 2021, 2024 гг.** с разбивкой по источникам.
4. **Декларации депутатов фракции 2018–2024 гг.** через declarator.org.
5. **Подтверждение информации о «Давиде Александровиче Гарсия»** (смена имени Игоря Лебедева) через ЗАГС или открытые источники реестров.
6. **Стенограммы заседаний этической комиссии Думы 21.03.2018 г.** (закрытое заседание; публичная стенограмма не опубликована).
7. **Поимённое голосование по ФЗ-255 (29.06.2022)** — точное число фракционного «за» / «против»; в открытой прессе только сводные цифры.
8. **Список соавторов ФЗ-365 (мобилизационные поправки)** — поимённый перечень со стороны ЛДПР.
9. **Финансовая структура «Партии дела» Бабкина** до перехода в ЛДПР; проверка пожертвований через ЕГРЮЛ.
10. **Имущественные споры наследников Жириновского** — окончательные судебные решения 2024–2026 гг.
