**Источник в коде:**

- `assets/js/charts/calculator.js:138`
- `assets/js/charts/calculator.js:152`
- `vybory.html:590`
- `assets/js/data/elections.js:232`

**Что не так / что говорят источники:**  
`324` уже является итоговым числом мандатов ЕР в Думе VIII созыва: `126` по федеральному округу и `198` по одномандатным округам. Пять самовыдвиженцев прошли в Думу отдельно, но не все “примкнули” к ЕР. Во фракцию ЕР вошли только двое: Владислав Резник и Леонид Бабашов. Дмитрий Певцов и Олег Леонов вошли во фракцию «Новые люди», Анатолий Вассерман - во фракцию СРЗП.

**Источники проверки:**

- Итоги выборов и мандаты: Российская газета / ЦИК, `126 + 198 = 324`  
  <https://rg.ru/documents/2021/09/24/itogi.html>
- Расклад по фракциям после выборов:  
  <https://www.interfax.ru/russia/796577>
- Руководство и состав фракции ЕР:  
  <https://rg.ru/2021/10/07/edinaia-rossiia-nazvala-rukovoditelej-frakcii-i-komitetov.html>

**Конкретное исправление:**

```diff
- 324 из 450, плюс 5 примкнувших самовыдвиженцев
+ 324 из 450; отдельно из пяти самовыдвиженцев двое вошли во фракцию ЕР
```

Для калькулятора:



и дефолт `0`, если калькулятор должен показывать официальный результат ЕР, а не расширенный “лояльный блок”.

## F3. Ошибка в расчёте “сгоревших” голосов и бонуса 5%-барьера

**Утверждение из сайта:**  
`Если бы 225 мест делили между всеми партиями (включая 10,92% непрошедших), ... ЕР ... получила бы только 112 мандатов вместо 126. ... Из 24 «бонусных» мандатов 58% получила ЕР.`

**Источник в коде:**

- `vybory.html:286`
- `assets/js/data/elections.js:30-41`
- `assets/js/pages/elections.js:38`

**Что не так / что говорят источники:**  
Партии ниже 5% получили около `8,85%` действительных голосов, а не `10,92%`. Число `10,92%` получается, если к партиям ниже барьера фактически добавить недействительные/прочие бюллетени. Это методологически можно показать отдельным слоем, но нельзя называть только “непрошедшими партиями”.

При распределении 225 мандатов методом Хэйра-Нимейера между всеми партиями, участвовавшими в федеральном округе, ЕР получила бы `115`, а не `112`. Следовательно:

- реальный результат ЕР по списку: `126`;
- результат ЕР без 5%-барьера: `115`;
- бонус ЕР от барьера: `+11`, а не `+14`;
- общий бонус проходных партий: `+20`, а не `+24`.

Дополнительно: в массиве `belowBarrier` у РПСС указано `0.75`, корректнее `0.77`.

**Проверочный пересчёт по официальным долям/голосам:**

| Партия | С барьером | Без барьера | Разница |
|---|---:|---:|---:|
| ЕР | 126 | 115 | +11 |
| КПРФ | 48 | 44 | +4 |
| ЛДПР | 19 | 17 | +2 |
| СРЗП | 19 | 17 | +2 |
| Новые люди | 13 | 12 | +1 |

**Источники проверки:**

- Ст. 89 20-ФЗ, метод распределения мандатов:  
  <https://www.zakonrf.info/doc-32922909/gl11-st89/>
- Итоговые результаты по партиям:  
  <https://www.rbc.ru/politics/21/09/2021/6149f8cf9a79470f9c953ac4>
- Итоги ЦИК/РГ:  
  <https://rg.ru/documents/2021/09/24/itogi.html>

**Конкретное исправление:**

```diff
- включая 10,92% непрошедших
+ включая 8,85% голосов за партии ниже 5%-барьера
```

```diff
- ЕР ... получила бы только 112 мандатов вместо 126
+ ЕР получила бы 115 мандатов вместо 126
```

```diff
- Из 24 «бонусных» мандатов 58% получила ЕР
+ Из 20 «бонусных» мандатов 11 получила ЕР
```

```diff
- { name: 'РПСС', share: 0.75 }
+ { name: 'РПСС', share: 0.77 }
```

## F8. “~20% от пришедших” в примере по одномандатным округам

**Утверждение из сайта:**  
`Реальные победители в 2021 брали мандат с ~20% от пришедших.`

**Источник в коде:**  
`vybory.html:249`

**Что не так / что говорят источники:**  
Арифметика демонстрационного примера верная:

- `500 000 × 40% = 200 000`;
- `35% от 200 000 = 70 000`;
- `70 000 / 500 000 = 14%`.

Но фраза про `~20% от пришедших` неверно называет знаменатель. `~20%` выглядит реалистично как доля от всех зарегистрированных избирателей округа, а не от явившихся. От пришедших победитель обычно получает около трети и выше.

**Конкретное исправление:**

```diff
- Реальные победители в 2021 брали мандат с ~20% от пришедших.
+ Реальные победители могли получать мандат при поддержке порядка 15-25% всех зарегистрированных избирателей округа; среди пришедших это обычно около трети и выше.
```

**Уровень:** 🟡 неточно

## B2. `distributeHareNiemeyer()` не моделирует ст. 88 20-ФЗ

**Источник в коде:**  
`assets/js/charts/calculator.js:4-19`

**Шаги воспроизведения:**

1. Вызвать распределение с одним списком выше 5% и остальными около нуля.
2. Например: ЕР `10%`, остальные `0`.
3. Функция отдаёт все `225` мандатов одному списку.

**Что не так:**  
Ст. 89 описывает распределение мандатов между списками, которые уже допущены к распределению. Но допуск определяется ст. 88. Там есть edge cases:

- если списки выше 5% суммарно получили `<=50%`, добавляются следующие списки до превышения 50%;
- если один список получил больше 50%, а остальные ниже 5%, к распределению допускается следующий список.

Текущий код делает только:

```js
const passing = parties.filter(p => p.share >= 5);
```

**Источники:**

- <https://www.zakonrf.info/doc-32922909/gl11-st88/>
- <https://www.zakonrf.info/doc-32922909/gl11-st89/>

**Предлагаемый фикс:**

```js
function getAdmittedLists(parties) {
  const positive = parties
    .filter(p => p.share > 0)
    .sort((a, b) => b.share - a.share);

  const admitted = positive.filter(p => p.share >= 5);
  let admittedShare = admitted.reduce((sum, p) => sum + p.share, 0);

  for (const party of positive) {
    if (admitted.length >= 2 && admittedShare > 50) break;
    if (!admitted.includes(party)) {
      admitted.push(party);
      admittedShare += party.share;
    }
  }

  return admitted;
}
```

Затем использовать `getAdmittedLists(parties)` вместо прямого фильтра `share >= 5`.

**Приоритет:** P1
