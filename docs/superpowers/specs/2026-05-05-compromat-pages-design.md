# Compromat pages — design spec

> **Дата:** 2026-05-05.
> **Контекст:** В рамках проекта `im-not-a-human.github.io/ru-elections/` собрана документальная база на 14 российских партий («Compromat research», см. `research/compromat/`). Объём — 151 000 слов синтеза + 233 файла на 190 МБ скачанных первоисточников. Нужно перевести это в публичные страницы сайта.
> **Тон:** аналитический, спокойный, без эмоциональных характеристик. Обыватель — первичная аудитория; эксперт — вторичная (видит источники).

---

## 1. Цель и аудитория

**Цель:** показать, что в легальном политическом поле России 2021–2026 гг. не существует партии, которая одновременно (а) представляет электоральную угрозу «Единой России», (б) структурно независима от государства и (в) последовательно голосует против ограничительных законов. Сделать это через прямые документы (поимённые голосования, госконтракты, декларации, указы) — не через интерпретацию.

**Первичная аудитория:** российский обыватель — читает по-русски, не углублён в правовую базу, оценивает конкретные кейсы (мобилизация, бюджет, цифровая слежка), а не идеологию.

**Вторичная аудитория:** журналист, исследователь, юрист — видит источники и может перепроверить.

**Что НЕ цель:** пропаганда, агитация, эмоциональные обвинения, выводы о коррупции конкретных лиц без приговора.

## 2. Карта сайта (site map)

| URL | Назначение | Статус |
|---|---|---|
| `/index.html` | **Главная — хаб «Партии»** (новое содержание + бывшая матрица) | редактируется |
| `/vybory.html` | Математика выборов (общий обзор системы) | без изменений |
| `/tsenzura.html` | Цифровые ограничения 2021–2026 (отдельная глубокая страница) | дополняется новыми данными |
| `/partii/<slug>.html` | **Глубокая страница каждой партии** (14 шт.) | новые файлы |
| `/sujety/<slug>.html` | **Сквозные сюжеты** (5–9 шт., по числу feature-карточек) | новые файлы |
| `/dokumenty.html` | **Документ-эксплорер** для всех скачанных первоисточников | новый файл |
| `/en/...` | Английские версии страниц | потом, не в этом цикле |

**Решения:**
- `index.html` объединяет: hero + карточки 14 партий + матрица голосований + сквозные сюжеты + ссылка на документы. Это «хаб», но при этом сохраняет роль главной страницы и заголовка «Голосование без выбора» как наследия.
- `tsenzura.html` остаётся полностью отдельной страницей (не сливается). Цифровые ограничения — самая востребованная тема, требует независимой подачи.
- `vybory.html` не относится к компромату, не трогаем (только при необходимости пунктуально дополним).
- Сквозные сюжеты не размазываются по партиям, потому что они кросс-партийные и объёмные. Каждый — своя страница.

Полный список slugs:

**Партии (`/partii/<slug>.html`):**
`er`, `kprf`, `ldpr`, `srzp`, `novye-lyudi`, `yabloko`, `partiya-rosta`, `grazhdanskaya-initsiativa`, `partiya-dela`, `rodina`, `kommunisty-rossii`, `pensionery`, `zelenye`, `rpss`, `grazhdanskaya-platforma` — 15 файлов (включая ЕР, чтобы было сравнение).

**Сюжеты (`/sujety/<slug>.html`) — 6 базовых:**

- `vneparlamentskie` — три ликвидации Партии дела/Гр. инициативы/Партии Роста

Опциональные сюжеты в будущем: `donbas-recognition` (КПРФ внесла проект ДНР/ЛНР), `presidential-grants` (Прилепин 40+ млн ₽), `goszakaz-grudinin` (1,37 млрд ₽ Совхозу им. Ленина).

## 3. Архитектура главной страницы (`index.html`)

Структура — длинный лонгрид с 5 секциями + sticky-TOC слева на десктопе.

### 3.1 Hero

- Меточный ряд: «Аналитический отчёт · 2019–2026 · 14 партий, 5 фракций»
- H1: **«Партий *четырнадцать*. Голос — <span style="color:#B91C1C">один</span>.»** (display, в стиле существующего hero `index.html`)
- Hero deck: один абзац-пояснение со ссылками `api.duma.gov.ru`, ЦИК, declarator.org
- Stats-блок: 4 крюка
  1. **300 тыс.** мобилизованных за 36 часов; 4 «оппозиции» — «за», ноль «против» 🟢 vote/119076
  2. **32,5%** бюджета-2025 на оборону; КПРФ и СРЗП воздержались, но не заблокировали 🟢 ФЗ-419
  3. **385/0/1** — голосование по цифровому рублю ФЗ-340; автор Аксаков (СРЗП) 🟢 vote/124183
  4. **700+** уголовных дел по ст. 207.3 УК «фейки об армии»; соавторы Зюганов и Миронов 🟢 bill 464757-7

Источник цифр: `02-cross-cutting/09-betrayal-cases.md`.

### 3.2 Раздел «Партии»

Три категории по горизонтали (для скролла идут вертикальными подсекциями):

**Парламентские (5):** ЕР · КПРФ · ЛДПР · СРЗП · НЛ
**Внепарламентские (4):** Яблоко · Партия Роста (ликв.) · Гр. инициатива (ликв.) · Партия дела (ликв.)
**Спойлеры и проекты (5):** Коммунисты России · Пенсионеры · Зелёная альт. · РПСС · Гр. платформа

Каждая карточка содержит:
- Цветную полосу слева (палитра `--party-*` из `tokens.css`)
- Название партии
- Лидера и число мандатов
- 2–3 ключевые цифры (поддержка ограничений %, доля бюджета %, доходы)
- Бейдж с ярким кейсом-крюком («Зюганов — соавтор ФЗ-32», «Луговой — соавтор ФЗ-255», «Аксаков — автор цифрового рубля»)
- Клик → переход на `/partii/<slug>.html`

### 3.3 Матрица «Голосования»

Это бывшее ядро `index.html` — обновляется с raw-XML из `api.duma.gov.ru`. Сохраняем существующий цветовой код состояний:
- 🔴 «за» (репрессивное, в нашей семантике — провластное)
- 🟢 «против»
- 🟠 «воздержались»
- ⚪ «не голосовали»

28 строк (28 ключевых законов 2019–2025) × 5 колонок (фракций). Числа в ячейках — поимённый расклад «за/против/возд./отс.» из `vote-summary.csv`.

Под матрицей — сводный текст про разделение «военно-репрессивная повестка ≠ социально-экономическая» (КПРФ голосует против пенсий и Конституции, но «за» войну).

### 3.4 Сквозные сюжеты

6 feature-карточек в grid-сетке. Каждая:
- Тематический ярлык («война и общество», «бюджет», «спойлерство», ...)
- Заголовок-крюк
- 1–2 предложения тизера
- «Читать →» → `/sujety/<slug>.html`

### 3.5 Документы

Краткая навигационная панель: «233 файла на 190 МБ — указы Президента, карточки sozd.duma.gov.ru, raw-XML голосований, OFAC SDN, UK Sanctions, Litvinenko Inquiry, тексты ФЗ, декларации, реестр иноагентов (1191 запись), госконтракты». Кнопка «→ Открыть эксплорер документов» ведёт на `/dokumenty.html`.

### 3.6 Sticky-TOC на десктопе

- Слева, ширина ~220 px, `position: sticky; top: 0`, `max-height: 80vh`, `overflow-y: auto`
- 5 пунктов содержания: Главное · Партии · Голосования · Сюжеты · Документы
- Активный пункт — тёмная плашка (фон `--ink`, цвет `--bg-card`)
- Под TOC — прогресс-бар «Прочитано N%»
- Скролл-spy через `IntersectionObserver` на корневых секциях
- На < 900 px sticky-TOC скрывается

## 4. Архитектура страницы партии (`/partii/<slug>.html`)

Длинный лонгрид с **sticky-TOC слева** (8 пунктов: A–H разделов досье + Источники).

### 4.1 Hero

- Метка: тип партии («Парламентская фракция» / «Внепарламентская» / «Спойлер»)
- H1: лозунг в стиле сайта («Новые люди — самая *чистая* управляемая оппозиция» и т. п.)
- Стат-блок: 4 цифры по этой партии (мандаты, доля поддержки, доля бюджета, ключевой кейс)

### 4.2 Секции (все открыты, ничего не скрыто)

Согласно структуре досье в `01-parties/<slug>/`:

- **A. Происхождение**
- **B. Финансирование**
- **C. Лидеры**
- **D. Связи с государством**
- **E. Голосование**
- **F. Управляемая оппозиция / спойлеры**
- **G. Кризисы и война**
- **H. Зарубежные связи** (только для непарламентских)

Каждая секция:
1. Заголовок-крюк (`H2`)
2. Один-два абзаца с inline-ссылками на источники `[название](url)`
3. Визуализация — график, таймлайн, диаграмма (см. ниже §5)
4. Дополнительный текст с фактами и числами
5. **В конце секции — единственный сворачиваемый блок «Источники и документы»** с группировкой 🟢🟡🟠🔴 и ссылками на скачанные на GitHub файлы

### 4.3 Графики/визуализации внутри секций

Делаем максимум визуализаций, чтобы заменить плотный текст:

| Секция | Визуализация |
|---|---|
| A. Происхождение | Сравнительная диаграмма сроков регистрации Минюстом (НЛ 3 мес vs ПАРНАС 18 мес vs Партия Прогресса 7 лет) |
| B. Финансирование | Stacked bar 2021–2024: бюджет / физлица / юрлица / иное |
| C. Лидеры | Карточки с фото + ключевые факты биографии + декларации |
| D. Связи | Таймлайн госнаград, должностей, контрактов; для контрактов zakupki — список с суммами |
| E. Голосование | Stacked bar по 28 ключевым законам — за/против/возд./отс. поимённо + ссылки на vote/<id>.xml |
| F. Спойлерство | Связной граф: партия → спойлер → округ |
| G. Кризисы | Таймлайн событий 2022–2024 с позицией партии в каждой точке |
| H. Зарубеж | Матрица «проверено NED/OSF/Heinrich Böll/... → найдено / не найдено» |

Используем **Chart.js** (он уже подключён через CDN в существующих страницах) + кастомный CSS-стэк для простых баров и таймлайнов.

### 4.4 Sticky TOC поведение

- Слева, ~220 px
- Скролл-spy: при прокрутке активный раздел подсвечивается
- Прогресс-бар чтения внизу TOC
- На мобильном — TOC скрывается; в шапке появляется кнопка «Содержание ↓» с раскрытием

## 6. Архитектура `/dokumenty.html`

**Цель:** дать возможность смотреть все скачанные первоисточники прямо на сайте, без переходов на российские госсайты.

**Подход:** GitHub-style file explorer с превью.

### 6.1 Слой данных

- Все артефакты лежат в `research/compromat/05-evidence/` репозитория (запушены в GitHub)
- Список файлов генерируется через GitHub Contents API: `https://api.github.com/repos/im-not-a-human/ru-elections/contents/research/compromat/05-evidence/<path>`
- Кэшируется в `assets/data/dokumenty-tree.json` (генерируется скриптом `scripts/build-dokumenty-tree.js` при коммите; запускается локально + в CI)

### 6.2 UI

- Левая панель (~280 px): дерево папок + файлов, кликабельное
- Правая панель: превью выбранного файла:
  - **PDF** — `<embed type="application/pdf" src="...">` или `<iframe>` с GitHub raw-URL (большинство браузеров рендерят PDF нативно)
  - **CSV / XLSX** — рендер таблицы через [SheetJS](https://github.com/SheetJS/sheetjs) (CDN)
  - **DOCX** — конверт через [mammoth.js](https://github.com/mwilliamson/mammoth.js) (CDN) → HTML
  - **HTML / XML / JSON / MD / TXT** — `<pre>` с подсветкой через highlight.js (уже подключаемый при необходимости)
  - **Картинки** — `<img>`
  - **Иное** — кнопка «Скачать»
- Поверху: breadcrumb текущего пути, поиск по имени файла, фильтр по типу

### 6.3 Источник файла для превью

Каждый файл — две ссылки:
- «Просмотр в репозитории» — на GitHub blob URL: `https://github.com/im-not-a-human/ru-elections/blob/main/research/compromat/05-evidence/<path>` (там GitHub сам рендерит PDF/XLSX/MD)
- «Скачать» — на raw URL: `https://raw.githubusercontent.com/im-not-a-human/ru-elections/main/research/compromat/05-evidence/<path>`

Превью на странице — fetch raw URL, рендер через SheetJS / mammoth / нативный браузер.

### 6.4 Производительность и ограничения

- Дерево файлов кешируется как JSON; не делаем 100 запросов к GitHub API на лету
- На превью — lazy-load (рендер только когда файл открыт)
- Большие файлы (>5 МБ) — только кнопка «Открыть в репозитории», не embedded
- На мобильном — дерево скрывается, открывается через кнопку

## 7. Tone, стиль, контент

### 7.1 Тон

- Описательный, без эмоциональных характеристик
- Никаких «марионетки», «холуи», «продались», «агенты Кремля» — только факты с источниками
- Различать факт (🟢 документ), деловую прессу (🟡), расследование одного источника (🟠), авторскую интерпретацию (🔴)

### 7.2 Заголовки-крюки

H1 — в стиле существующего сайта: italic для эмоционального слова + accent-color для ключевого. Примеры:
- «Партий *четырнадцать*. Голос — <span class="accent">один</span>.» (главная)
- «Новые люди — самая *чистая* управляемая оппозиция.» (NL)
- «КПРФ — *оппозиция*, которая голосует <span class="accent">«за»</span>.» (KPRF)
- «Яблоко — единственное *исключение*. И почему его *удерживают*.» (Yabloko)

### 7.3 Источники в тексте

- **Inline-цитата** — каждое утверждение, требующее источника, имеет `<a href="...">[источник]</a>` прямо в строке
- **Блок «Источники и документы»** в конце каждой секции — полный список с группировкой 🟢🟡🟠🔴

## 8. Стили и токены

### 8.1 Палитра

Используем существующие токены из `assets/css/tokens.css` (см. файл) — никаких новых palette.

Особенно:
- `--bg: #F0EAD6` (cream)
- `--ink: #1A1815` (dark)
- `--accent: #B91C1C` (red)
- `--party-*` (5 партийных цветов)
- `--vote-*` (цвета голосований)

### 8.2 Новые компоненты CSS

В новый `assets/css/partii.html` (или общий `compromat.css`):

- `.toc-side` — sticky-TOC layout
- `.party-card`, `.cat-grid` — для хаба
- `.chart-card` — обёртка вокруг Chart.js / SVG / самописных баров
- `.timeline` — для таймлайнов кризисов и хронологий
- `.sources-fold` — единственный сворачиваемый блок «Источники»
- `.evidence-explorer` — для документов

Никакого `tokens.css` не трогаем.

## 10. Доступность (accessibility)

Сохраняем существующие правила проекта (см. `CLAUDE.md`):
- Все интерактивные элементы доступны с клавиатуры
- ARIA-роли на TOC, аккордеоны
- Контраст ≥ WCAG AA
- `prefers-reduced-motion` отключает анимации
- Нет JS — текст контента остаётся читаемым (контентоориентированная серверная отдача через статический HTML)

## 11. Технический стек

Никакого нового билд-инструментария — следуем правилам проекта (`CLAUDE.md`):

- Чистый HTML, CSS, vanilla JS
- Chart.js через CDN (уже подключён)
- SheetJS через CDN — для XLSX/CSV в эксплорере
- mammoth.js через CDN — для DOCX в эксплорере
- highlight.js через CDN — для подсветки JSON/XML/MD при необходимости
- IntersectionObserver — для scroll-spy TOC

Один новый Node-скрипт: `scripts/build-dokumenty-tree.js` — генерирует JSON-дерево файлов из `research/compromat/05-evidence/`. Запускается локально + в CI на pre-commit.

## 14. Поэтапная реализация

Объём — большой, не один спринт. План разделения на фазы (детально — в writing-plans):

## 15. Обработка ошибок и устойчивость

- **404** на несуществующие slug-ы партий и сюжетов — стандартная страница 404 с возвратом на главную
- **Ошибка fetch** для документ-эксплорера (GitHub API rate-limit) — graceful fallback: показать кэшированное JSON-дерево + сообщение «не удалось обновить, показано последнее закешированное»
- **Превью PDF** не работает в браузере — fallback на «Скачать» + «Открыть в репозитории»
- **Большой XLSX** замедляет браузер — preview ограничен первыми 1000 строк + сообщение «полный файл — скачать»
- **Большой DOCX** — то же ограничение
- **Без JS** — все основные страницы (`index.html`, `/partii/<x>.html`, `/sujety/<x>.html`) рендерятся как полноценный текст; теряются только Chart.js-графики и интерактивный TOC. Основной контент остаётся читаемым (по правилам проекта).

## Финальный тезис, который должен поддерживаться структурой страниц

> В легальном политическом поле России 2021–2026 годов не обнаруживается партии, которая одновременно (а) представляет устойчивую электоральную угрозу «Единой России», (б) не зависит от государственных механизмов допуска, финансирования или парламентской инфраструктуры, и (в) последовательно голосует против ключевых ограничительных и военных законов. Партии различаются по стилю и электорату, но в кризисных голосованиях 2022–2025 действовали как часть единого государственного блока. Это видно по конкретным голосованиям, конкретным контрактам, конкретным семейным связям — а не по риторике на сайтах партий.

Структура страниц должна давать читателю возможность это проверить на любом утверждении — отсюда обязательность inline-ссылок и блока «Источники и документы» в каждой секции.
