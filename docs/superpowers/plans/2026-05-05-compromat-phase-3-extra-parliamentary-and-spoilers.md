# Compromat Phase 3 — Extra-Parliamentary & Spoiler Party Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать 9 глубоких страниц партий (`/partii/<slug>.html`) для 4 внепарламентских и 5 спойлерных партий, повторяя структурный шаблон Phase 2 (sticky-TOC + hero + N секций A–H + sources-fold). Phase 1 (хаб на главной) и Phase 2 (5 парламентских) уже в `main`.

## Общий шаблон страницы

Каждая страница повторяет структуру `partii/novye-lyudi.html` / `partii/kprf.html`:

1. **`<head>`** — title (party-specific), meta description, OG title/description/url, canonical, favicon SVG, fonts preconnect, CSS-ссылки (`tokens, base, layout, components, home, partii`), JS marker `documentElement.classList.add('js')`
2. **Skip-link** + **topnav** (Главная активна, ссылки на vybory/tsenzura)
3. **Crumb**: `<a href="../index.html">Главная</a> / <a href="../index.html#parties-extended">Партии</a> / <Название партии>`
4. **`<section class="party-hero">`** с meta-row, H1, lead-paragraph, 4 hero stats
5. **`<div class="party-page-layout">`** (sticky TOC слева ≥1080px + контент справа)
6. **`<aside class="party-toc">`** с N TOC-entries (по числу секций), `data-target` совпадает с `data-toc-id` секций
7. **N `<section class="party-sec">`** — каждая секция с `id`, `data-toc-id`, `<div class="party-sec-mark">A · ...</div>`, h2-крюк, 3-5 параграфов с inline-ссылками, sources-fold в конце
8. **Inline `<script>`**: `window.renderPartyContent` — для партий с timeline (Yabloko, Partiya Rosta, Gr-Init, Partiya Dela, Zelenye) рендерит timeline в нужный `<div id="...Timeline">`. Для остальных — пустая функция или skip.
9. **5 component scripts** в правильном порядке:
   ```html
   <script src="../assets/js/lib/scroll-spy.js"></script>
   <script src="../assets/js/components/vote-bar.js"></script>
   <script src="../assets/js/components/timeline-vert.js"></script>
   <script src="../assets/js/components/sources-fold.js"></script>
   <script src="../assets/js/pages/party.js"></script>
   ```
